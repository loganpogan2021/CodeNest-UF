# CodeNest-UF

En enkel statisk webbplats byggd med HTML, CSS och lite JavaScript.  
Projektet innehåller grundläggande struktur med `index.html` och `style.css`.

## Struktur
- `index.html` – huvudfilen för hemsidan  
- `style.css` – design och styling  
- `lxweb/` – övriga filer som tillhör projektet

## Kör projektet
Öppna `index.html` direkt i webbläsaren.
